Beginner Level

1. Pronouns

Learn: I, You, He, She, It, We, They

2. Verb to Be

Learn: am, is and are

3. Present Simple

Learn about habits, routines and facts.

4. Present Continuous

Learn about actions happening now.

5. Past Simple

Learn about actions that happened in the past.

6. Past Continuous

Learn about actions happening at a specific time in the past.

7. Present Perfect

Learn about experiences, results and actions connected to the present.

8. Past Perfect

Learn about an action that happened before another action in the past.

9. Present Perfect Continuous

Learn how to talk about actions that have been continuing until now.

10. Past Perfect Continuous

Learn how to talk about an action that continued before another action in the past.

11. Future Simple

Learn how to talk about future actions and plans.

12. Modal Verbs

Learn how to use can, could, should and must.

13. Adverbs

Learn how to describe how, when and how often actions happen.

14. Adjectives

Learn how to describe people, places and things.

15. Prepositions

Learn common prepositions of place and time.

16. Questions

Learn how to ask common questions in English.

17. Comparatives and Superlatives

Learn how to compare people, places and things.

18. Linking Words

Learn: and, but, because, so and or.

19. Passive Voice

Learn how to use the Passive Voice.

20. Reported Speech

Learn how to report what someone said.
